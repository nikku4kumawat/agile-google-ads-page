# Agile Solutions - Google Ads Hero Section

Files included:
- index.html
- css/style.css
- js/script.js
- images/agile-office-background.png
- images/agile-solutions-logo.png
- images/reference-design.png

Features:
- Responsive header and Google Ads hero section.
- Desktop/laptop: logo + clickable phone + WhatsApp quote button.
- Mobile: logo + quote button only; phone number hidden as requested.
- Background uses the supplied Agile office image.
- Supplied Agile Solutions logo is used directly.
- Desktop heading is designed for 2 lines.
- Mobile heading is limited to 3 visual lines.
- Desktop hero buttons stay on one line.
- Stats appear below buttons and become a 2x2 grid on mobile.
- Form moves below the stats on mobile.
- Select service includes all requested Google Ads services.
- Form submission opens WhatsApp with all entered details.
- Call buttons use tel:+918005677079.
- WhatsApp buttons use 918005677079.

Run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. For best testing, use Chrome/Edge responsive device mode for desktop, tablet and iPhone/Android widths.

Note:
Font Awesome is loaded from its CDN in index.html, so icons require an internet connection. The supplied photos/logo are local and included in the package.
